# Security and privacy

StockLint processes files in the browser. It has no backend, account system, analytics, or third-party runtime assets. Source files are not transmitted by the app. The CSV export escapes formula-like cell values, but users should still inspect spreadsheet imports and treat untrusted files carefully.

If you discover a security issue, avoid posting exploit details or private data in a public issue. After the GitHub repository is published, use its private vulnerability reporting feature if enabled. Until then, contact the maintainer using the public contact method in the profile. Do not attach live customer data.

Supported version: the latest release on the main branch. Security response times are not guaranteed for this volunteer-maintained preview.
