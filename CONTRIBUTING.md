# Contributing

Thanks for helping StockLint. Keep changes focused on reproducible inventory CSV problems.

1. Open an issue explaining the behavior and use synthetic sample data. Do not post a real client's CSV.
2. Run `npm test` before proposing a change.
3. Add a test when changing CSV parsing, validation, or export safety.
4. Explain what users should review manually and avoid claims that a file is ready for a specific vendor without verified schema support.
5. Keep the default app local-first, dependency-light, and accessible by keyboard.

By contributing, you agree to license your contribution under the repository's MIT license.
