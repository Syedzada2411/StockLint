# StockLint roadmap

This is a proposal, not a promise of funded work or delivery dates. Public progress should be tied to merged changes and released examples.

## Current preview (v0.1)

- Local CSV upload or fictional demo, manual field mapping, quality checks, audit log, reviewed CSV export.
- Basic automated tests and setup guide.

## Milestone 1 · Safer review

- Editable correction preview with explicit approve/reject per row and undo.
- Severity filters, clear error categories, and larger-file performance checks.
- Screen-reader and keyboard review with documented accessibility fixes.

**Evidence of completion:** tests for correction/undo; public demo using fictional data; accessibility findings and fixes documented.

## Milestone 2 · Reusable rules

- User-defined column aliases and validation presets saved locally.
- Duplicate resolution suggestions shown for human approval; never automatic SKU renaming.
- More sample catalogs and import/export guide for generic CSV workflows.

**Evidence of completion:** versioned rule format, tests, and examples with fictional data.

## Milestone 3 · Community-ready release

- Internationalization foundation, with English and Urdu translations reviewed by native speakers.
- Opt-in, anonymized bug reproduction workflow; no collection by default.
- Reproducible release process and contributor documentation.

**Evidence of completion:** tagged release, translation review, and public changelog.

## Funding use

If support becomes available, publish a budget and progress updates before spending it. Proposed categories are implementation time, testing/accessibility review, documentation/translation, and hosting for a static demo. Sponsorship or grants are not guaranteed. Feature requests and data samples must not contain private customer information.
